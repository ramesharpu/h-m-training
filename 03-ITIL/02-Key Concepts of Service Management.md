# ITIL 4 Foundations — Service Management Concepts

## Training Notes with Examples

---

# 1. What is Service Management?

---

# Definition

Service Management is:

```text id="sm1aa"
A set of specialized organizational capabilities for enabling value for customers in the form of services.
```

---

# Simple Explanation

Service Management helps organizations:

* Deliver reliable IT services
* Meet business needs
* Improve customer experience
* Manage risks and costs

---

# Examples of IT Services

| Service             | Example                 |
| ------------------- | ----------------------- |
| Cloud hosting       | AWS infrastructure      |
| Email service       | Corporate mail system   |
| Banking application | Online banking          |
| Streaming platform  | Video streaming service |
| Internal IT support | Helpdesk support        |

---

# Goal of Service Management

Provide:

* Business value
* Reliability
* Availability
* User satisfaction

---

# Modern Service Management

Modern organizations combine:

* ITIL
* DevOps
* Agile
* SRE
* Cloud platforms

to deliver faster and more reliable services.

---

# Example

## E-Commerce Website

Service management ensures:

* Website uptime
* Fast checkout
* Payment availability
* Customer support
* Incident handling

---

# Service Management Workflow

```text id="sm2bb"
Business Need
      ↓
IT Service Designed
      ↓
Service Delivered
      ↓
Monitoring & Support
      ↓
Continuous Improvement
```

# 2. Value and Value Co-Creation

---

# What is Value?

Value is:

```text id="sm3cc"
The perceived benefits, usefulness, and importance of something.
```

---

# Important Idea in ITIL 4

Value is not created only by the provider.

It is:

```text id="sm4dd"
Co-created between provider and consumer.
```

---

# What is Value Co-Creation?

Both parties contribute to creating value.

---

# Example: Food Delivery App

## Service Provider

Provides:

* Application
* Delivery system
* Payment platform

## Customer

Provides:

* Order information
* Payment
* Usage feedback

Together:

```text id="sm5ee"
Value is created through interaction.
```

---

# Traditional vs Modern Thinking

| Traditional               | Modern ITIL 4         |
| ------------------------- | --------------------- |
| Provider delivers value   | Value is co-created   |
| Customer receives service | Customer participates |
| IT-focused                | Business-focused      |

---

# Real IT Example

## Cloud Service

Provider:

* Maintains infrastructure

Consumer:

* Configures workloads properly

If customer misconfigures:

* Service value decreases

---

# Value Co-Creation Flow

```text id="sm6ff"
Service Provider
       ↔
Service Consumer
       ↓
Shared Value Creation
```

# 10. Value: Outcomes, Costs, and Risks

---

# Outcomes

Desired results achieved by users.

---

# Example Outcomes

| Service         | Desired Outcome         |
| --------------- | ----------------------- |
| Banking app     | Successful transactions |
| E-commerce site | Completed purchases     |
| Email service   | Reliable communication  |

---

# Costs

Resources consumed to achieve outcomes.

Examples:

* Infrastructure costs
* Licensing fees
* Support staff

---

# Risks

Possible negative impacts.

Examples:

* Downtime
* Data breaches
* Performance failures

---

# Value Formula Concept

```text id="sm9ss"
Value = Desired Outcomes
        - Costs
        - Risks
```

---

# Real Example

## Cloud Hosting

### Outcomes

* Fast deployments
* High uptime

### Costs

* Monthly cloud bill

### Risks

* Security threats
* Service outages

---

# Goal of Service Management

Maximize:

* Outcomes

Minimize:

* Costs
* Risks

# 11. Utility and Warranty

---

# Utility

Utility means:

```text id="sm0tt"
“Fit for purpose.”
```

Does the service provide required functionality?

---

# Example

## Video Streaming Platform

Utility:

* Watch movies online
* Search content
* Stream videos

---

# Warranty

Warranty means:

```text id="sm1uu"
“Fit for use.”
```

Does the service work reliably?

---

# Warranty Includes

| Area         | Example             |
| ------------ | ------------------- |
| Availability | 99.9% uptime        |
| Capacity     | Supports many users |
| Security     | Protected access    |
| Continuity   | Backup/recovery     |

---

# Utility vs Warranty

| Utility                | Warranty                |
| ---------------------- | ----------------------- |
| What service does      | How well it performs    |
| Features/functionality | Reliability/performance |

---

# Real Example

## Food Delivery App

### Utility

* Place orders
* Track delivery

### Warranty

* App available during peak hours
* Fast response times

---

# Another Example

## Cloud Storage Service

### Utility

* Store files

### Warranty

* Secure access
* High availability
* Fast retrieval

---

# Combined Value Example

```text id="sm2vv"
Utility + Warranty = Service Value
```

---

# Enterprise Example

## Banking Platform

### Utility

* Money transfer
* Account management

### Warranty

* 24x7 availability
* Secure transactions
* Fast processing
