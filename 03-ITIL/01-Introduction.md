# 1. What is IT Service Management (ITSM)?

---

# Definition

IT Service Management (ITSM) is the process of:

* Designing
* Delivering
* Managing
* Improving

IT services for users and businesses.

---

# Simple Explanation

ITSM ensures:

```text id="itil1aa"
“Technology services support business needs effectively.”
```

---

# Examples of IT Services

| Service              | Example                |
| -------------------- | ---------------------- |
| Email service        | Corporate email        |
| Cloud infrastructure | AWS/Azure environments |
| Banking applications | Online banking         |
| E-commerce platforms | Shopping websites      |
| Internal IT support  | Employee helpdesk      |

---

# Goal of ITSM

Provide:

* Reliable services
* Fast issue resolution
* Business value
* Better customer experience

# 4. History of ITIL

---

# Origin of ITIL

ITIL was created in the 1980s by:

```text id="itil1kk"
UK Government’s Central Computer and Telecommunications Agency (CCTA)
```

Goal:

* Standardize IT service management practices.

---

# Why ITIL Was Needed

Organizations faced:

* Inconsistent IT operations
* Frequent outages
* Poor service quality
* Lack of standard processes

---

# Evolution of ITIL

| Version | Year  | Focus                                 |
| ------- | ----- | ------------------------------------- |
| ITIL V1 | 1980s | Basic operational guidance            |
| ITIL V2 | 2000  | Process standardization               |
| ITIL V3 | 2007  | Service lifecycle                     |
| ITIL 4  | 2019  | Agile, DevOps, digital transformation |

---

# ITIL Evolution Diagram

# 5. Comparison: ITIL V3 vs ITIL 4

---

# Why ITIL 4 Was Introduced

ITIL V3 worked well for traditional IT environments.

But modern IT introduced:

* Agile
* DevOps
* Cloud
* CI/CD
* Automation

ITIL 4 modernized ITSM practices.

---

# Core Difference

| ITIL V3                  | ITIL 4                      |
| ------------------------ | --------------------------- |
| Process-focused          | Value-focused               |
| Lifecycle model          | Service value system        |
| Traditional IT           | Modern digital services     |
| Siloed operations        | Collaboration               |
| Limited DevOps alignment | Strong Agile/DevOps support |

---

# ITIL V3 Lifecycle Model

```text id="itil3mm"

       ↓
Service Design
       ↓
Service Transition
       ↓
Service Operation
       ↓
Continual Service Improvement
```

---

# ITIL 4 Value System Model

```text id="itil4nn"

   ↓
Service Value System
   ↓
Value Creation
```

---

# ITIL V3 vs ITIL 4 Comparison Table

| Area            | ITIL V3           | ITIL 4            |
| --------------- | ----------------- | ----------------- |
| Main Focus      | Service lifecycle | Value co-creation |
| Processes       | Central focus     | Practices focus   |
| DevOps Support  | Limited           | Strong            |
| Agile Alignment | Weak              | Strong            |
| Automation      | Minimal           | Major emphasis    |
| Collaboration   | Less emphasized   | Highly emphasized |
| Flexibility     | More rigid        | More adaptable    |
